# MiniMax 网页录音与飞书回传

用户目前选择使用 MiniMax 网页已有积分。官方接口需要独立权限时，不要求用户为了自动化购买接口会员；网页路线可独立使用。开始浏览器任务先读 `ego-browser` 技能并运行其指南，复用 Ego Lite 登录态。

## 先分清授权

- 研究接入、查看音色、下载已有录音、生成新录音是不同动作。沿用本次已经给出的授权，不重复问已经确定的参数。
- 用户说“先不要生成”时，不点击 Generate，不用“测试”消耗生成积分、不重新克隆、不购买或充值。可按授权用历史文件验证下载与回传。
- 用户之后明确要求生成时，才执行生成。先核对稿件范围、音色、参数和预计费用；缺少的必要决定再问。网页余额、上限、模型与计费以当时页面为准。

## 网页操作

1. 打开 [MiniMax Audio](https://www.minimax.io/audio/text-to-speech)，检查登录与页面。到 Voice Library → My Voices 核对用户已有音色，再到生成页确认选中正确音色。不默认换系统音色，不因网页已有音色就宣称接口也可用。
2. 提取用户指定当前脚本的纯口播。排除制作备注、未确认口径及无需朗读的提示词；只在朗读文本中处理 LibTV 等读音，不改课程正文。
3. 读取当前文本上限与模型、语速、音调、音量等参数，按自然段拆分，保存“课节—段落—稿件版本—任务—文件”对应关系。未经确认的句子单列，不让机器念出“待确认”。
4. 有实际生成授权后再点 Generate。等待任务完成；超时先查 History，确认未提交或确已失败才补交，避免重复花积分。按页面实际能力依次处理，不盲目并发开多个生成页面。
5. 下载时先挂下载事件，再点击 MP3 或 WAV，且在同一轮保存到绝对路径。不能只记录临时下载地址，也不能把浏览器临时文件当最终交付。
6. 本地核对格式、时长与完整解码；生成录音还要检查漏段、重复及错读，必要时转写核对。已有历史样例的下载测试不代表新稿朗读质量已验证。
7. 按用户指定位置用飞书 CLI 上传，再读取文档确认附件位置和名称。有需要可下载回本地比对文件。无回填授权时只交付本地文件；不要自动替换正式课程的“暂无”。

## 已验证的历史下载入口

2026-10-17 在 Text to Speech → History 中，已有录音条目使用 `.tts-history-item`；悬停后 `.ant-dropdown-trigger` 打开 MP3／WAV 菜单。仅用作定位线索，下次先看当前页面，不能盲点第一条。

- 先从条目文案、音色、日期时间确认目标；同文多条时按记录或位置消歧。
- 等菜单出现后，再挂 `waitForEvent('download')` 并点击指定格式，立即 `saveAs(绝对路径)`。
- 页面加载迟到时，先等可观察的目标状态；动作后重新查看，不把暂时旧画面当失败并重复点击。
- 不导出登录 Cookie，不把网页会话当永久接口凭据；技能和普通记录不保存凭据、临时签名下载链接。
- 完成浏览器任务后，按 Ego Lite 指南结束任务空间；用户需要操作时交还控制，不能绕过接管。
