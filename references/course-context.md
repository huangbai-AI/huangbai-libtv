# 课程背景与资料入口

## 项目约定

- 项目名称：libtvx 黄白｜ AI 视频实战课；对外品牌正文统一 `LibTV`，项目标题以用户当前确认为准。
- 黄白：主讲、拍摄；LibTV：后期剪辑、配套画布与资料。
- 正式12节：导学、画布与节点、图片生成与提示词、视频生成与提示词、Agent与Skill、AI影视进阶、AI创意玩法、AI短剧／漫剧、AI带货广告、AI MV、AI特效、总结与活动。备选不自动加入正式课。
- 具体课名、案例、排期和商业权益可能继续调整；每次读最新版，不把此处当锁定终稿。

## 使用顺序

1. 读用户本轮要求、指定的最新版与其亲自修改部分。
2. 读黄白课程总纲中“五、教程策划”，确定该节目标与正式范围。
3. 读该节当前完整文档和用户已改口播；先在工作记录整理或确认有效大纲，再依据其前三列编写脚本，执行 [三列大纲／七列脚本标准](table-standard.md)。
4. 需要恢复或对照时，再读指定的原讲师版；它提供已打磨的教学展开，不提供黄白的个人经历或永久有效的产品事实。
5. 总纲与旧脚本冲突时记录具体位置；确定的先改，待外部确认标红、内部待定标黄。不为统一课纲擅自把完整脚本缩成摘要。
